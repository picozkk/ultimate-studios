# Ultimate Studios

Premium Minecraft plugin showcase website.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Upload this repository to GitHub, import it into Vercel, and deploy with the default Next.js settings.

## Current products

- UltimateTPA — Available
- UltimateRTP — In Development
- UltimateRTPQ — Early Development
- UltimateHOMES — Early Development
- UltimateAC — Flagship / In Development
- More Products — Coming Soon

## Security note

This public starter intentionally contains no plugin JARs and no public download endpoint. When the client dashboard is added, JAR downloads should be protected server-side with authentication + license checks.
